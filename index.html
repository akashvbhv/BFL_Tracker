System Logic Quick Guide

Accurate tracking using Bajaj Finserv Overdraft methodology.

1. User Provisioning

Add profiles via sidebar. Creation or deletion requires the Master Password. If Master is unset, actions are unrestricted.

2. Interest Calculation Logic

Calculated daily based on the closing principal balance. Mid-month payments reduce interest costs immediately.

3. Monthly Capitalization

On the 1st of every month, accumulated daily interest is converted into an "Accrued Interest" entry and added to the principal.

4. Custom Interest Logic (Per Entry)

Define a Global Rate in settings. Override this for specific periods by entering a Specific Rate in a transaction; it applies until changed.

5. Corrections & Auditing

Editing or deleting past entries triggers an automatic full timeline recalculation to update current balance instantly.
