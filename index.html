Mastering the Ledger System

This application follows the Bajaj Finserv Overdraft logic for accurate loan tracking.

1. User Provisioning

New profiles can be added via the sidebar. Any creation or deletion of a member profile requires the Master Password for authorization.

2. Interest Calculation logic

The system calculates interest daily based on the closing principal balance. This ensures that payments made mid-month reduce interest costs immediately.

3. Monthly Capitalization (Accrued Interest)

On the 1st of every month, all daily interest accumulated over the previous month is converted into a transaction named "Accrued Interest" and added to the principal balance.

4. Corrections & Auditing

Past entries can be edited or deleted. The system will automatically trigger a full recalculation of the timeline to update the current balance instantly.

5. Security Access

Each ledger is password protected with individual passwords.
