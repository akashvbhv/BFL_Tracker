System Logic Quick Guide

Accurate tracking using Bajaj Finserv Overdraft methodology.

1. User Provisioning

Add/Delete profiles via sidebar. These actions require the Master Password.

2. Interest Calculation Logic

Calculated daily based on closing principal balance. Mid-month payments reduce interest immediately.

3. Monthly Capitalization

On the 1st of every month, interest is converted into an "Accrued Interest" entry and added to the principal.

4. Custom Interest Logic

Define a Global Rate or override it using a Specific Rate within any transaction.

5. Corrections & Auditing

All manual entries are deletable. System interest rows are updated automatically based on your manual changes.
